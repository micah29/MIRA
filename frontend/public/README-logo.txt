MIRA logo files (served at the site root)

  logo.png              ATW Solar logo with dark lettering, for the light login card
  logo-white.png        ATW Solar logo with white lettering, for the blue sidebar
  favicon.png           Browser tab icon (64 x 64), the ATW panel symbol
  apple-touch-icon.png  Icon when MIRA is added to a phone home screen (180 x 180)

To change the logo later, replace them with official high-resolution files
using the SAME file names (PNG with transparent background is best),
then restart the frontend (or rebuild Docker: docker compose up -d --build).
If logo.png is missing, MIRA falls back to the plain text logo.
